# Examples

Runnable examples are small, public-facing Gleam projects:

- `congruency` shows semantic congruency checks, transformed subpath matching,
  and the fact that closed subpaths are not cycled to find another starting
  segment.
- `abstract_convex_hull` is an experimental convex-hull project kept as a
  larger reference example.

Debug probes live in `debug`. They are scratch files and generated drawings
used while developing geometry algorithms. They may be useful for investigation,
but they are not curated API examples.
